## What we build

Reltio is the **Context Intelligence Platform** powering agentic AI in the enterprise. Our open-source repositories give developers, partners, and customers the tools to connect AI agents to trusted, real-time master data — securely and at scale.

**[AgentFlow™](https://www.reltio.com/platform/agentflow/)** is Reltio's agentic AI platform. It enables autonomous agents — resolvers, enrichers, verifiers — to act on high-quality, governed enterprise data using the **[Model Context Protocol (MCP)](https://modelcontextprotocol.io/)**: an open standard for structured, semantically rich agent-to-API communication.
